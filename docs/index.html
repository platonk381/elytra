Вопросы

Частые вопросы

Это бесплатно?

Да, полностью. Без рекламы, подписок и платных функций.

Windows пишет «Система Windows защитила ваш компьютер»

Так Windows реагирует на любую программу без платной цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае». Исходный код Elytra открыт на GitHub.

Нужна ли лицензия Minecraft?

По правилам Mojang для игры нужна купленная копия Minecraft. Elytra скачивает файлы игры только с официальных серверов Mojang и ничего не взламывает.

У меня не открывается Modrinth или игра долго качается

Elytra сама проверяет, какие сайты работают в твоей сети, и при необходимости качает через зеркала. Состояние видно в Настройки → Источники загрузки.

Можно перенести сборки из другого лаунчера?

Да: Библиотека → «Перенести из другого лаунчера». Поддерживаются Modrinth App, CurseForge, Prism, MultiMC, TLauncher и официальный лаунчер.

Как обновлять Elytra?

Никак — она сама предложит обновиться, когда выйдет новая версия.
