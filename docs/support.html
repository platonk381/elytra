Техподдержка Elytra

Большинство проблем решается за минуту. Найди свою ниже — или отправь отчёт прямо из лаунчера.

ЗапускWindows пишет «Система Windows защитила ваш компьютер»
  1. Нажми «Подробнее».
  2. Нажми «Выполнить в любом случае».

Так Windows встречает любую программу без платной цифровой подписи. Код Elytra открыт на GitHub.

ЗапускАнтивирус удаляет Elytra или пишет «троян»

Это ложное срабатывание: так антивирусы реагируют на программы на Python, упакованные PyInstaller.

  • Скачивай Elytra только с этого сайта или со страницы GitHub.
  • Добавь папку %LOCALAPPDATA%\Programs\Elytra в исключения антивируса.
  • Для Microsoft Defender можно отправить файл как ложное срабатывание на microsoft.com/wdsi/filesubmission.
ЗапускElytra не открывается или открывается пустое окно
  1. Открой Диспетчер задач (Ctrl+Shift+Esc) и сними задачу у всех «Elytra».
  2. Запусти Elytra снова.
  3. Если окно пустое — обнови Microsoft Edge WebView2 (обычно стоит в Windows 10/11, скачивается с сайта Microsoft).
  4. Не помогло — переустанови Elytra через Elytra-Setup.exe: сборки и миры сохранятся.
СетьНе открывается каталог модов (Modrinth)
  1. Открой Настройки → Источники загрузки и подожди 10 секунд проверки.
  2. Если Modrinth «недоступен» — выбери «Только зеркала».
  3. Проверь интернет и VPN: в логе это видно как «Нет связи с …».
СетьСборка качается очень долго
  • Первая установка новой версии Minecraft скачивает несколько сотен мегабайт — это нормально. Следующие сборки на той же версии создаются почти мгновенно.
  • Forge и NeoForge всегда ставятся дольше: после скачивания запускается их собственный установщик.
  • Пока ждёшь — нажми «Поиграть, пока ждём» в уведомлении.
ИграИгра вылетает при запуске
  1. Открой сборку → «Ещё» → «Доктор»: он найдёт конфликтующие моды и нехватку памяти.
  2. Нажми «Починить» — Elytra перепроверит все файлы игры.
  3. Попробуй отключить недавно добавленные моды.
  4. Не помогло — отправь отчёт (см. ниже), приложи лог.
Игра«Java не найдена»

Нажми «Починить» у сборки — Elytra сама скачает нужную Java. Если в Настройках указан свой путь к Java, очисти поле.

ИграМало FPS, лагает
  • Открой сборку и нажми «Ускорить» — поставятся моды оптимизации.
  • В Настройках сборки дай игре больше памяти (обычно 4–6 ГБ хватает).
  • Шейдеры сильно нагружают видеокарту — попробуй без них.
МодыКак перенести сборки из другого лаунчера?

Библиотека → «Перенести из другого лаунчера». Elytra сама найдёт сборки Modrinth App, CurseForge, Prism, MultiMC, TLauncher и официального лаунчера.

МодыСборка «Сломана» и не запускается

Так бывает, если закрыть Elytra во время установки. Нажми «Починить» — установка продолжится. Сборку также можно удалить.

АккаунтНе отображается скин

Скин берётся по нику с серверов Mojang. Если ник не привязан к лицензии — показывается стандартный скин. Проверь ник в Настройках.

АккаунтКак обновить Elytra?

Elytra сама покажет баннер «Доступна новая версия» — нажми «Обновить». Если что-то пошло не так, скачай Elytra-Setup.exe с этого сайта и запусти поверх.

Ничего не нашлось — отправь отчёт, разберёмся.

Отчёт о проблеме

Отправь отчёт за 30 секунд

Отчёт сам соберёт версию, сведения о системе и лог ошибок — личных данных и паролей в нём нет.

В Elytra открой Настройки и нажми «Сообщить о проблеме» (или Ctrl+K → «Сообщить о проблеме»).
Отчёт скопируется, и откроется форма на GitHub — коротко опиши, что случилось.
Вставь отчёт в поле «Отчёт Elytra» (Ctrl+V) и нажми Submit.
