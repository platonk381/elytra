# Elytra

A modern Minecraft launcher for Windows.

- One-click mods, modpacks, shaders and resource packs from Modrinth
- Fabric, Quilt, Forge and vanilla instances
- FPS boost, instance doctor, world backups, mod updates
- 3D skin viewer, achievements, play stats, Discord status
- Two themes (Emerald and Aurora), 5 languages (EN, RU, UK, DE, ES)
- Works in networks where Modrinth or Mojang are blocked (automatic mirrors)

## Download

Get `Elytra.exe` from the [Releases](../../releases) page and run it. No installation required.
Windows SmartScreen may warn about an unknown publisher: click **More info → Run anyway**.

## Build from source

Requires Python 3.10+. Run `install.bat`: it installs dependencies, builds `Elytra.exe`
and adds desktop and Start menu shortcuts. For development, use `run.bat`.
